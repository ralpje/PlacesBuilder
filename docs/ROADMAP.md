# Roadmap

What may come next for the self-hosted app. It is a list of intentions, not a promise: there are no dates, and the order can change with feedback. Each item has an issue; that is where the discussion and the status are.

Have you tried the app? Open a [feedback issue](https://github.com/ralpje/placesbuilder/issues/new?template=feedback.yml).

## Verify against Microsoft Places

## How this list is kept
Issues carry the labels `roadmap`, `idea`, `blocked`, `feedback` and `imdf-question`. When an item is finished, its issue is closed by the pull request and the line is removed here.
