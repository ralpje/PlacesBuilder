- Use, run, copy and modify the code as the AGPL allows.
- Say that your software is *based on* or *a fork of* Places Builder, and link to this repository.
- Refer to the project by name where needed to describe it accurately, for example in a blog post or a comparison.
- Run Places Builder in your own organisation, for example in your own Azure subscription, and call that installation what you like inside your organisation.

## What you may not do without written permission

- Offer a service to others under the name Places Builder, a confusingly similar name, or the official logo, or in a way that suggests it is the official service or is endorsed by the project.
- Use the reserved domain names, or similar ones meant to be confused with them.
- Present a modified version as the official release.

If you publish a fork or offer your own service, choose your own name and logo and state clearly that it is not the official Places Builder.
